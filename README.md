## 💎 Project Overview

MeCod Labs represents an integrated product studio tailored for high-ticket US and European founders, startups, and product teams. The portfolio is built strictly in **Silicon Valley Light Mode** following the 60-30-10 color discipline, 8pt spatial grid, and Apple Human Interface Guidelines (44pt touch ergonomics).

- **Dominant Canvas (60%):** Crisp porcelain surfaces (`#FAFAFC` / `#FFFFFF`) eliminating eye strain.
- **Structural Contrast (30%):** Deep Slate (`#0F172A`, `#334155`) with hairline dividers (`rgba(15, 23, 42, 0.08)`).
- **Action Energy (10%):** Electric Indigo (`#4F46E5`) paired with Cyber Mint (`#10B981`) status indicators.
