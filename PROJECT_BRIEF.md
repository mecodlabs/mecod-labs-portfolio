# Project Brief: MeCod Labs Portfolio
**Brand Name:** MeCod Labs (Media & Code Labs)  
**Tagline:** *Where Media Aesthetics Meet Precision Code.*  
**Target Audience:** High-ticket international clients (Upwork, US/EU Startups, SMBs) looking for top-tier Design-Engineers.  
**Visual Style:** Clean Silicon Valley Light Mode • Electric Indigo (`#4F46E5`) & Cyber Mint (`#10B981`) accents • Crisp porcelain canvas.  

---

## 1. Brand Identity Assets
* **Logo Mark:** `<Me/Cod>` aperture-bracket monogram icon.
* **Core Value Proposition:** Solo & agile team capabilities delivering complete products—from initial Figma UI/UX and media assets to production Flutter/Kotlin mobile apps, Next.js web dashboards, and zero-defect QA handoff.
